# PreCogn & Structory — Public Projects

A directory of public open-source projects and engineering resources maintained by the PreCogn / Structory ecosystem.

Our work explores AI-native software, user-controlled data, and human-directed automation. Each project remains an independent repository with its own history, issues, releases, and contribution workflow.

## Projects

| Project | Description | Repository |
|---|---|---|
| **PreCogn Cockpit** | Human-directed coordination of persistent AI coding agents, with verifiable workflows and human control over merges and deployments. | [Precogn-org/precogn-cockpit](https://github.com/Precogn-org/precogn-cockpit) |
| **Vivace** | Open-source tooling to keep Claude Code Remote Control sessions available on an always-on Linux machine. | [Precogn-org/vivace](https://github.com/Precogn-org/vivace) |
| **Structory Green** | Environmental indicators module for Structory, starting with an estimate of avoided greenhouse-gas emissions for BYOS architectures. | [Precogn-org/green](https://github.com/Precogn-org/green) |
| **ChatGPT Remote Agent Workflow** | A practical, human-controlled workflow for remote software development with ChatGPT, a VPS, coding agents, and GitHub. | [Precogn-org/chatgpt-remote-agent-workflow](https://github.com/Precogn-org/chatgpt-remote-agent-workflow) |

## Principles

- **Human-directed:** people retain control over consequential actions.
- **Verifiable:** prefer evidence, tests, reviewable changes, and explicit limitations.
- **Open source:** each repository publishes its own license and contribution terms.
- **Independent projects:** this directory links to projects; it does not combine or duplicate their source code.

## Contributing

Please open issues or pull requests in the repository relevant to your contribution. Read that project's README and license before using or contributing to it.
